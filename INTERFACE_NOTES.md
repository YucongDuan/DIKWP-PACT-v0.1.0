## Scope and verification

Canonical option values, input values, structured data, code blocks and existing research evidence are preserved. Original-language cases, quotations, specialist terminology and historical release archives may retain Chinese. Translations do not establish or strengthen a research claim.

Static checks covered HTML structure, script syntax, creator credits and preservation of canonical values. Isolated localization checks covered language changes, dynamic text, numeric messages and protected data. Browser preview was blocked by the environment URL security policy, so this update does not claim end-to-end browser validation.
